# Project Statement

## Problem

Managing student marks, attendance, and academic performance manually can be time-consuming and error-prone.

## Proposed Solution

The Student Performance Management System provides a console-based Java application for maintaining student information, managing marks and attendance, generating individual performance reports, and viewing class-level statistics.

## Objectives

1. Maintain student records.
2. Manage academic marks.
3. Track attendance.
4. Generate performance reports.
5. Provide class-level performance statistics.
6. Store student information using file-based persistence.
7. Validate user input and handle common errors safely.

## Expected Outcome

The system provides a simple and organized method for managing student academic performance using Java and object-oriented programming concepts.
