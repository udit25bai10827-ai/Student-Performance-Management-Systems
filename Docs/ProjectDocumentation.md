# Student Performance Management System

## Project Overview

The Student Performance Management System is a Java-based console application for managing student academic information.

## Core Components

- Student management
- Marks management
- Attendance management
- Performance reports
- Dashboard statistics
- File-based data persistence
- Input validation

## Technology

- Java
- Object-Oriented Programming
- Java Collections
- File I/O
- Exception Handling

## Purpose

The system provides a simple way to maintain student records and evaluate academic performance through marks, attendance, reports, and summary statistics.
